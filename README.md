# I'm Sorry 💜💛 — Apology Website

A static, purple-and-yellow apology website (HTML, CSS, vanilla JS). No backend, no API keys, no cost.

## Folder structure
```
apology-website/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Upload to GitHub
1. Sign in at github.com and click **New repository** (e.g. `sorry`). Set it to **Public** and create it.
2. Click **uploading an existing file**, drag in `index.html`, `style.css`, `script.js` and `README.md`.
3. Click **Commit changes**.

## Turn on GitHub Pages
1. Open **Repository → Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then click **Save**.
4. Wait 1–2 minutes and refresh the Pages screen.

## Open and share
Your site will be live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`. Open it on your phone and computer to check, then send her the link.

## Notes
- All paths are relative, so it works as a GitHub Pages project site.
- Colors are CSS variables at the top of `style.css`.
- Animations are turned off for visitors who prefer reduced motion.
- The No button runs away 7 times, then stays put. If she taps it, she gets a kind reply instead of pressure.
